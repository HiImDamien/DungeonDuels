## Short description (tagline)

Race through your own dungeon for 63 seconds, then duel your friend with everything you found.

## Description

**DungeonDuels** is a two-player, split-screen dungeon crawler that ends in a duel.

You and a friend each get your own dungeon and 63 seconds. Clear rooms of bats and slimes, grab an
upgrade from every room you finish, and take down the big slime boss for a new bullet mode. When
the clock runs out, you both drop into a single arena with everything you collected. Last one
standing wins.

- Local two-player split screen: share a keyboard and a controller, or use two controllers
- Upgrades that stack: fire rate, max health, shields, speed and combining bullet modes
- A shield that blocks shots but breaks if you lean on it too long
- Solo mode to try it out on your own

**Playing alone?** Join with one device, ready up, then press A / Enter again to start solo.

## Controls

Each player picks one device on the join screen. Left side is Player 1, right side is Player 2.

| Action | Keyboard | Controller |
|---|---|---|
| Move | W A S D | Left stick |
| Aim | Arrow keys | Right stick |
| Shoot | Arrow keys (aiming fires) | RT / R2 |
| Shield | Space | LT / L2 |
| Pause | Esc / P | Start / Options |
| Confirm / back | Enter / Backspace | A / Cross, B / Circle |

**Controller not showing up?** Browsers only see a controller after you press one of its
buttons, so press a button on the join screen. If that doesn't work, connect the controller first
and then restart your browser.
